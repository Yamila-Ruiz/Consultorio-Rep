# Nuevo frontend del consultorio

Aplicación React + Vite que conserva el tema visual y las vistas del frontend original, con un layout propio basado en Material UI.

## Desarrollo

```bash
npm install
npm run dev
```

Configura `VITE_API_URL` en un archivo `.env` si la API no está disponible en `http://localhost:3001/api`.

## Vistas

Incluye Inicio, Citas, Pacientes, Servicios, Pagos, Facturación, Terapeutas e Inicio de Sesión. Las vistas de administración mantienen sus formularios, validaciones y llamadas a la API originales.
